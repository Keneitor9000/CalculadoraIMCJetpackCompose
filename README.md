# CALCULADORA IMC

Aplicación Android para calcular el Índice de Masa Corporal (IMC), desarrollada con Kotlin y Jetpack Compose. Cuenta con una interfaz moderna y personalizada

## Tecnologías
- Android Studio
- Java/Kotlin

## Instalación

1. Clona el repositorio:
   ```bash
   https://github.com/Keneitor9000/CalculadoraIMCJetpackCompose.git
   ```
2. Abre el proyecto en Android Studio.
